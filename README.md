# Calculator Project

A team project for Intro to Python Programming.

## Getting started

You need Python 3.10 or newer.

1. Clone the repository:

   ```
   git clone https://github.com/brooke-brown/calculatorproject.git
   cd calculatorproject
   ```

2. Create and activate a virtual environment:

   ```
   python3 -m venv .venv
   source .venv/bin/activate
   ```

   On Windows, activate it with `.venv\Scripts\activate` instead.

3. When you're done working, leave the environment with `deactivate`.
